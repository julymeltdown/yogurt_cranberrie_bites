`startProductionFrontend` accepts an optional `communityClock` descriptor with exactly `path`, `sha256` and `current`. The CLI accepts the optional seventh argument naming an owned private descriptor JSON file. Its input path must name an owned, private, regular, nonsymlink UTF-8 file of at most 512 KiB with the supplied SHA-256. The exact bytes are compiled as `import.meta.env.VITE_MCR_COMMUNITY_CLOCK_INPUT`; no reserialization, environment-file discovery or fallback measurement is used. An absent descriptor compiles explicit `undefined`.

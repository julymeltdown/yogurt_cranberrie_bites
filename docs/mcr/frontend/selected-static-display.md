# Selected-source static display

Status: IN_PROGRESS. This is a public illustration consumer prepared for the first six selected-source front-idle derivatives. It does not replace the C06 avatar contract, assign an authenticated person's appearance, or establish AR03/IN01 acceptance.

The human authorized source-preserving crops and background masks on 2026-11-04 and required near-identical source fidelity with minimal client/server transfer. Originals remain unchanged. The art owner writes `frontend/public/world/avatars/derived-v1/static-release.json` and its reviewed atlas; the frontend king owns `frontend/src/entities/avatar/selected-static/**`. No backend, source originals, contract registries, manifests, dependencies or lockfiles are changed by this consumer.

`SelectedStaticGallery({ count: 4 })` is a decorative landing illustration, with optional `className`. It validates source-pack revision 3, the exact selected photo_01 hash, six source-local illustration IDs, front-idle pose, fixed 64px frames and anchor, local PNG paths, and atlas dimensions/hash before display. These source-local IDs must never be submitted as canonical AvatarConfig item IDs. Missing, rejected or unavailable artwork remains absent; there is no legacy/generated fallback. The gallery is hidden from assistive technology because it adds no account or interaction information.

The release format is `mcr-selected-static-v1`. It includes source pack ID/revision, pose `front_idle_only`, art-owner `reviewed_by`/`reviewed_at`, one `atlas` descriptor (`path`, `sha256`, `width_px:384`, `height_px:64`), and six `characters` records. Each character has local ID `photo01-front-01` through `06`, label, selected source ID/hash, `frame:{x:index*64,y:0,width_px:64,height_px:64}`, and `anchor:{x:32,y:60}`. Review fields record the author's contour and source-preservation evidence; they do not add a human approval gate. Native-resolution cutouts and their provenance remain with the art package.

Successful loads share one bounded public release/atlas promise across concurrent consumers and navigation/era changes. There are two static requests, no per-character/frame request, no credentials, no outfit data in API payloads, and no private response cache. Object URLs are view-owned and revoked on unmount. A failed load clears the shared promise for a future deliberate mount; there is no polling or automatic retry loop. Quality at large avatar sizes and actual authenticated appearance binding remain separate work.

Validation at the initial implementation checkpoint: two focused provenance/cache tests pass; whole-frontend strict TypeScript and scoped Oxlint pass (all exit 0). The tests reject changed source hashes, traversal paths, fabricated pose/frame metadata, and verify one atlas request shared by concurrent and later consumers. Native visual evidence and source-pixel acceptance await the actual art handoff. No static fixture or test marks a real user, save, animation or multiplayer flow accepted.

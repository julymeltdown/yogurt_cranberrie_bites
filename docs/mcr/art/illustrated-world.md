## Editable inputs and provenance

All new resources are in `frontend/public/world/illustrated/`. `build.cjs` is the editable deterministic composition source. It reads the immutable AR02 map and creates fifteen SVG documents: ground, landmarks, composite scene, isolated landmark atlas and terrain tiles for each era. Every SVG retains individually named object groups and external original-image references. Ground and native details are editable vectors; the five generated object interiors remain raster pixels, not separately editable vector illustrations.

The five `*-original.png` files retain the generated bytes unchanged. They came from the built-in `image_gen` tool with transparent backgrounds; no input reference image was submitted for editing, no command-line fallback was used, and no dependencies were installed. Exact prompts are in [prompts.json](evidence/illustrated-world/prompts.json). The built-in tool did not expose a model version. No third-party stock material or font files were added; SVG labels use the browser's generic sans-serif font. This records creation provenance without asserting a separate third-party license grant.

## Binding proposal and immutable geometry

`binding-proposal.json` is a source proposal, explicitly not a release manifest. It pins source bytes and copies the existing place, landmark, spawn and interaction identities. The map stays 36×28 at 32px per cell (1152×896), collision ID `paradise_virtual_collision_v1`, geometry hash `sha256:463a46ba69bcb48fc691cc33c76e53a43328473edf8b8b61c235d96043dc9e27`. The original geometry, Tiled map, landmarks and supplied reference are byte-identical to the assigned base. Nothing in the art implies physical arrival or route authority.

Each era has these exports:

| Resource | Dimensions | Intended use |
| --- | --- | --- |
| `{era}-ground.png` | 1152×896 | Opaque ground at depth -1 |
| `{era}-landmarks-atlas.png` | 768×512 | Individual y-sorted scenery objects using exact source rectangles |
| `{era}-landmarks.png` | 1152×896 | Transparent static preview layer with labels, banners and lamps |
| `{era}-scene.png` | 1152×896 | Static source comparison and overview only |
| `{era}-terrain-tiles.png` | 256×128 | Optional reusable terrain IDs 1–8; IDs 9–32 remain transparent |

The terrain texture is **not** a complete replacement C06 theme atlas. An integrator must explicitly bind the new object composition and qualify asset registries. Ground plus the selected era's landmark atlas totals approximately 520–541 kB (decimal), with 5.44 MiB raw RGBA pixels before renderer overhead. Exact transfer sizes are in the export receipt. Do not load all source originals or all era previews into the product. Native detail resource generation and actual texture upload/memory measurements remain integration work.

Landmark sprite placement uses top-left origin and `depth_y` equal to the art base. Player foot depth shares this y ordering. Do not put the complete foreground PNG above all players: it would give incorrect occlusion. Labels attach to their corresponding landmark at its depth; the plaza label is a ground/DOM label. Native SVG `banner-*` and `lamp-*` groups have individual base depths recorded in the proposal. They are decorative details with no new collision authority; canopy overhang likewise never creates a blocked cell.

## Added runner support

contexts and a separate operator context. It selects a naturally existing
bounded connected region in the real qualified seed; it does not fabricate a
raster or silently seed a database. It exercises explicit UI pencil, opaque erase,
four-connected fill and eligible own-last-action undo. All 16,384 opaque cells
and authoritative snapshot/revision are compared on both editor canvases and
through the required producer-owned read-only world-texture witness. One
persistent world canvas and one active/peak passive C05 connection are required.
There is no proposed C05 mural extension or second socket.

A successful action is bound to original operation, exact closed body, key,
actor, event, receipt, action, revision, changed count, cooldown and undo expiry.
New tools must force snapshot-reset compatibility; they never masquerade as a
single-pixel operation. The independent expected-effect oracle checks bounded
four-connected fill and opaque erase without calling the production preview
implementation. Undo compares the actual pre-action grid and charges the same
server budget; it never refunds the original cost or rewinds revision.

The same actor's pencil/tool cooldown is checked concurrently and shared budget
is checked across all tools and authenticated reload. A remote actor's write
invalidates own undo. A lost-response branch forwards one actual POST to the
real server, discards only its actual response, reloads the canonical app and
recovers via GET status and exact original result/action. Pending, missing and
malformed/wrong-scope results cannot acknowledge a command or cause another
POST/key. A terminal FAILED receipt can retire only its bound attempt, following
the producer's frozen reasons. Public deltas and foreign-key reads are checked
for private-data leakage.

Member moderation attempts must fail. The actual qualified operator then pauses,
resumes, locks/unlocks, restores the named baseline into a newer revision,
releases delayed real obsolete delta bytes, observes reconnect and an actual
external restart/new epoch, and finally freezes the isolated event. Unknown
operator outcomes stop the journey; they are never inferred from requested
controls. Final freeze intentionally leaves only the explicitly owned isolated
event frozen. Failed execution requires operator reconciliation of retained
original keys and the named snapshot, not an automatic mutation replay.

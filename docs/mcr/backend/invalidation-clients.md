## Public consumer API

Module: `concert_service::adapters::out::relationship_authority::invalidation`.
`InvalidationSource::new(owner, endpoint, credential, &TlsMaterial)` requires
HTTPS and pins the expected Auth/Friend TLS workload. Every operation uses the
retained Concert credential interceptor, without actor JWT or delegation.

`read_head(consumer, &ReplayBudget)` returns a `VerifiedOwnerHead`.
`read_after(consumer, OwnerCursor, limit, &ReplayBudget)` returns a
`VerifiedOwnerPage`. Cursors restored with `OwnerCursor::new` are untrusted input.
Verified heads/pages/signals have private fields and no public raw/protobuf/JSON
conversion or deserializer. Only authenticated client responses can construct
them. Read-only getters expose the exact echoed query, owner, epochs, positions,
stable signal identity, closed reason and closed User/Family/Pair scope.

`ReplayBudget::new(original_stop, cancellation)` and `for_duration` enforce a
positive at-most-one-second lifetime. The original stop covers lazy channel
readiness, RPC, decoding and structural validation; a shorter ambient call
deadline wins. Reusing a spent budget cannot restart its timer. Cancellation
drops the pending future. There is no retry. Errors and Debug output omit private
query/signal contents and peer diagnostics.

Every page requires exact consumer/request/after/limit echo, `no-store`, canonical
nonzero UUIDs, safe cursor range, one epoch, contiguous positions, bounded page
and frame size, next equal to the final signal and no short incomplete page.
Unknown reasons, foreign owners, invalid/exclusive scope combinations, repeated
identities and conflicting content fail closed. `VerifiedSignal::check_redelivery`
compares retained sealed records without I/O. Across-page/restart deduplication
and effect receipts belong to World's durable ledger; this client has no global
cache and never advances a checkpoint or changes authority.

The owner RPCs deliberately sanitize both changed-epoch and future-position
rejections as `FAILED_PRECONDITION`; the client exposes `CheckpointMismatch` for
that status. It distinguishes `EpochChanged` and `FutureCursor` when the received
response itself provides enough structural evidence. It does not infer a hidden
server cause or add a follow-up read with a fresh budget.

World must fence old cached authority, capture a baseline, perform existing typed
authority rereads, apply intervening signals and durably record effects before
advancing a checkpoint. A head/page is replay evidence, never arrival, permission,
readiness, or extension of the current two-second Auth lease/five-second C05 cap.
World/admission/startup/configuration wiring remains separately owned.

## Application and checkpoint order

One stable consumer identity equals its configured World owner identity. Auth and Friend positions are independent. A short Concert-local run lease fences competing consumers; it is not an authorization grant. Up to sixteen actual event bridges share one suppression gate. Bootstrap suppresses publication, removes old active/pending views under their actual native fences, cancels affected parent operations, drains production permits, and disconnects the stable consumer's old SQL generations before any head read. A retained same-epoch cursor resumes its applied position; an explicitly invalidating bootstrap can establish a new source epoch baseline. A future same-epoch cursor is rejected.

Each operation uses one monotonic budget of at most one second, including source readiness, validation and local application. Each source page is bounded to 256 signals. Backlog suppresses admission and publication; caught-up polling is scheduled every 125 ms, within the contract's 250 ms bound. Readiness expires after 250 ms without a new qualified check. A known nonempty page suppresses handoff before waiting for local serialization or SQL. No signal extends a credential or lease, and clearing a removal marker reinstalls no view. Fresh publication still uses actual typed Auth/Friend/Profile/Concert reads.

Local receipt metadata binds source owner/epoch/sequence, stable signal identity, reason and exact user/family/pair scope. Native removal precedes SQL disconnection. Exact victims, immutable effects and the corresponding applied cursor commit in one transaction. Duplicate application uses captured connection/family/owner generations; it cannot revoke a freshly authorized replacement generation. A failed/cancelled transaction retains native removal markers. Unknown/query/gap/epoch/source failures suppress and fence all local views, requiring an explicit invalidating bootstrap before serving again. Local Concert outbox/closure application remains the existing separate producer path and keeps its fanout obligations.

Migration `0026_world_remote_invalidation.sql` adds only local run/checkpoint/effect tables. Source journals remain owned by Auth and Friend. The World production startup's existing publication gap remains closed until this increment is actually qualified; adding constructors does not enable serving.

# Synthetic default-shell Feed qualification

This document is a test entry, not an alternate production application or an actual IN03 deployment. `preview.html` mounts the default `createAppRoutes` composition with `createProductionPorts`, one canonical Auth controller, Root's character registry and Root's protected-media provider. There is no replacement Feed panel, static character renderer, media-preview controller or World socket. World is explicitly disabled in the synthetic C03.

`fixture.ts` preserves the two approved reference texts, names, relative two/four-hour timestamps, counts and complete media crops from immutable `eb6e81bd7e5fbeb15613a45e00f1fe896e49f0da`. It intentionally replaces historical avatar configs with selected static C06 presets 03/04. The browser clock is fixed to `2026-11-04T12:00:00Z`. Media uses the canonical metadata/content decoder and Blob lifecycle; the explicit test transport verifies the approved PNG hashes before returning bytes. No private server access is claimed.

Modes are `loaded`, `no-readiness`, `denied-media`, `thread` and `notice`. All except `no-readiness` supply explicit synthetic Feed readiness. Missing readiness never falls back to C03 flags. Unsupported mutations remain unavailable. Native checks reach the real composer without submitting a fabricated successful command, then withdraw readiness and exercise canonical logout/Blob cleanup. Thread and Notice are fixture-only modes using actual default routes/controllers. The existing declared “A test reply” and “Fixture notice” source paths, Git blobs and scope adaptations are exposed as `shapeProvenance`; no production data is changed.

Run only under a fresh named resource offer that has actually been accepted. Use retained absolute Node 24.22.2 and read-only dependencies; no install, build, database or shared writable checkout is required. `qualify.mjs` owns the temporary dependency link, cache/TMP, process groups, guards and cleanup. Its whole ledger charges preserved carry, both source contributions, owned Git metadata and unpublished logical Git objects. It samples process/RSS, file/byte, free-space and UTC work limits every 250ms. Every attempt uses a new run identifier and retains failures.

Source mode runs scoped types, six Feed guards, lint and native-driver syntax. `MCR_FEED_ADMISSION=1` additionally runs the nine original Auth admission guards and original-harness types. Native mode (`MCR_FEED_NATIVE=1`, admission absent) avoids those unchanged suites: it checks changed fixture types and driver/supervisor syntax, starts one allocated strict-port Vite server, and opens one Chromium browser with sequential contexts. `MCR_FEED_CSS_REVISION` and `MCR_FEED_CSS_SHA256` bind the Feed owner's immutable product CSS; the runner borrows it into a read-only private file without editing `feed.css`.

Required allocation inputs are `MCR_FEED_CARRY`, `MCR_FEED_NODE`, `MCR_FEED_DEPENDENCIES`, `MCR_FEED_ALLOCATION`, `MCR_FEED_RUN`, `MCR_FEED_ACTIVE_UNTIL`, `MCR_FEED_MAX_FILES`, `MCR_FEED_MAX_BYTES`, `MCR_FEED_MAX_PROCESSES` and `MCR_FEED_MAX_RSS_BYTES`. Native mode additionally requires the allocated `MCR_FEED_PORT`, Feed CSS pins and `MCR_FEED_ROOT_CSS_REVISION` / `MCR_FEED_ROOT_CSS_SHA256`. The latter borrows Root's exact `cozy-community-backgrounds-v1.css` through the same read-only mechanism; no shared file is written. Optional paired `MCR_FEED_ROOT_MEDIA_REVISION` / `MCR_FEED_ROOT_MEDIA_SHA256` borrow only the Root owner's exact `RootMediaView.tsx`, served at its original module ID with normal relative imports. The supervisor sets private TMP/cache/output paths and pinned child PATH. No environment value itself grants an allocation.

`MCR_FEED_POST_ONLY=1` checks established non-post Feed typography, red tabs/compose controls and restored shared backdrop, with retro styling confined to actual post surfaces. `MCR_FEED_POST_SHAPES=1` adds one 390px Thread with a populated comment and one 390px Notice context, including its Feed notice-list presentation. It checks actual card styles, 44px targets, keyboard focus and Auth withdrawal. Feed and Thread use a reported temporary inert driver spacer to exercise actual observer exit/return geometry. New fixture TypeScript requires its scoped type check; do not set `MCR_FEED_SKIP_PASSED_TYPES=1` for this changed fixture. Root owns qualification of the borrowed shared component itself. Historical broad-retro results remain immutable and do not accept the latest post-only visual scope.

Native artifacts include full-shell 360/390/430×843 and short 390×480 captures, complete-media and painted-character crops, shell/body/scroll geometry, composer reachability, one decoded Root atlas, denied-media and missing-readiness behavior, and cleanup. Their acceptance remains open until execution and image assessment.
